## 📖 Sobre o Projeto

Esta é uma aplicação web feita para você registrar seus **Capitais de Graça** e ajudar o **Jumas Seberi** a alcançar a conquista de 2025: o quadro de heróis.

## ✨ O que são os Capitais de Graça?

Pense nos Capitais de Graça como um **"tesouro espiritual"**. Eles são:

- 🙏 Suas orações
- ✝️ Seus sacrifícios
- 😊 Suas alegrias
- 💪 Seus sofrimentos
- ❤️ Suas boas obras
- 📚 Seus esforços para se autoeducar

Tudo isso você oferece à Maria, que transforma em graças e as distribui do Santuário para quem mais precisa. É uma forma linda de contribuir e fazer a diferença!

## 🎯 A Conquista do Ano: Nosso Grande Objetivo!

Todo ano, o Jumas Seberi define uma **conquista** especial. Essa conquista é o nosso grande objetivo para o ano, e pode ser qualquer coisa com um significado espiritual profundo para o nosso momento.

## 💻 Desenvolvimento Local

Se você quer colocar as mãos na massa e configurar este projeto na sua máquina para desenvolver ou testar, siga estes passos simples:

### Pré-requisitos

- Node.js (versão 18 ou superior)
- npm ou yarn

### Instalação

1. **Clone o repositório:**

   ```bash
   git clone https://github.com/Gabriel-RQ/capitalario-jumas-seberi-2025
   cd landing-page-jumas-seberi
   ```

2. **Instale as dependências:**

   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**

   ```bash
   npm run dev
   ```

4. **Acesse a aplicação:**
   
   Abra seu navegador em `http://localhost:5173` para ver a landing page funcionando em tempo real. Divirta-se! 🎉
