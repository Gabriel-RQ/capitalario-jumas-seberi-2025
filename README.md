# Capitalário dos Heróis 🚀

Esta é uma aplicação web feita para você registrar seus **Capitais de Graça** e ajudar o **Jumas Seberi** a alcançar a conquista de 2025: o quadro de heróis.

## O que são os Capitais de Graça? ✨

Pense nos Capitais de Graça como um "tesouro" espiritual. Eles são todas as suas orações, sacrifícios, alegrias, sofrimentos, boas obras e esforços para se autoeducar, que você oferece à Maria. 🙏 Ela, por sua vez, transforma tudo isso em graças e as distribui do Santuário para quem mais precisa. É uma forma linda de contribuir e fazer a diferença!

## A Conquista do Ano: Nosso Grande Objetivo! 🎯

Todo ano, o Jumas Seberi define uma **conquista** especial, que buscamos alcançar por meio de uma meta de Capitais de Graça. Essa conquista é o nosso grande objetivo para o ano, e pode ser qualquer coisa com um significado espiritual profundo para o nosso momento.

## Detalhes Técnicos 🤓

Este projeto foi construído com as seguintes tecnologias:

- **SvelteKit**: Um framework moderno para criar interfaces de usuário incríveis.
- **Tailwind CSS**: Para estilização rápida e eficiente.
- **TypeScript**: Para um código mais robusto e livre de erros.

## Quer Rodar o Projeto Localmente? É Fácil! 💻

Se você quer colocar as mãos na massa e configurar este projeto na sua máquina para desenvolver ou testar, siga estes passos simples:

1.  **Clone o repositório:**

    ```bash
    git clone https://github.com/Gabriel-RQ/capitalario-jumas-seberi-2025
    cd landing-page-jumas-seberi
    ```

2.  **Instale as dependências:**

    ```bash
    npm install
    ```

3.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm run dev
    ```

Depois disso, é só abrir seu navegador e acessar `http://localhost:5173` para ver a landing page funcionando em tempo real. Divirta-se!
